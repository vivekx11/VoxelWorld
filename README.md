#  VoxelWorld – Build Your Own World (Beta v1.0)

![VoxelWorld Banner](https://img.shields.io/badge/Version-v1.0--Beta-green?style=for-the-badge) ![Platform](https://img.shields.io/badge/Platform-Windows%20PC-blue?style=for-the-badge) ![License](https://img.shields.io/badge/License-MIT-orange?style=for-the-badge)

Welcome to **VoxelWorld**, an immersive 3D sandbox voxel building PC game! Explore endless possibilities, craft blocks, build structures, and create your own unique world in this open-ended 3D universe.

---

## Features

- **🎮 3D Voxel Engine:** Rich, interactive 3D voxel sandbox environment.
- **🧱 Building & Crafting:** Place and destroy various voxel block types in real-time.
- **🖥️ Dedicated Web Showcase:** Sleek, modern website featuring controls, roadmap, and instant game download.
- **📦 Windows Executable Included:** Pre-built standalone PC game included inside the `VoxelWorld/` directory (`VoxelWorld.exe`).

---

##  Controls

| Action | Control Key |
| :--- | :--- |
| **Move Forward / Backward** | `W` / `S` |
| **Move Left / Right** | `A` / `D` |
| **Jump** | `Spacebar` |
| **Place Block** | `Right Click` |
| **Break Block** | `Left Click` |
| **Select Block Type** | `1` - `9` Number Keys |
| **Pause / Menu** | `Esc` |
